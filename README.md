# Onegin Task

Создал массив, хранящий строки текстового файла.

## Библиотеки:

| Библиотека | Описание |
|---|---|
| `<stdio.h>` | Подключение работы ввода-вывода |
| `<stdlib.h>` | Подключение базовых функций С (в моем примере - `calloc`) |
| `<sys/types.h>` | Определение новых типов данных для работы со структурой stat |
| `<sys/stat.h>` | Определение структуры `stat` |
| `<assert.h>` | Кто не ставит ассерты - тот на завтрак ест десерты |


## Переменные:

| Тип | Переменная | Назначение |
|---|---|---|
| `size_t` | `num_symbols` | Количество символов в тексте |
| `char*` | `buffer` | Массив, хранящий текст |
| `int` | `count_of_strings` | Количество строк в тексте |
| `char**` | `index` | Массив указателей на строки |
| `struct stat` | `text` | Структура, хранящая данные о файле |
| `int` | `string_num` | Номер строки в массиве строк |
| `FILE*` | `onegin` | Указатель на текстовый файл |

## Функции:

  ### `Get_Text_From_File`
  ```c
  char* Get_Text_From_File(size_t* num_symbols);
  ```
  **Тип:** `char*`
  
  **Принимает:** указатель на количество символов
  
  **Возвращает:** буффер, хранящий текст

  <br>
  
  Открывает файл, сохраняет структуру, создает буффер, хранящий текст, и возвращает его.

  ---

  ### `Strings_Count`
  ```c
  int Strings_Count(char* buffer, size_t num_symbols);
  ```
  **Тип:** `int`
  
  **Принимает:** буффер с текстом, количество символом в тексте
  
  **Возвращает:** количество строк в тексте

  <br>
  
  Подсчитывает количество строк в тексте.

  ---

  ### `Strings_Arr`
  ```c
  char** Strings_Arr(char* buffer, size_t num_symbols, int count_of_strings);
  ```
  **Тип:** `char**`
  
  **Принимает:** буффер с текстом, количество символом в тексте, количество строк в тексте
  
  **Возвращает:** массив указателей на строки

  <br>
  
  Создает массив строк и возвращает его.

  ---

  ### `Get_String`
  ```c
  char* Get_String(char** index, int num, int count_of_strings);
  ```
  **Тип:** `char*`
  
  **Принимает:** массив строк, номер элемента `num`, количество строк в тексте
  
  **Возвращает:** элемент `num` массива строк

  <br>
  
  Проверяет выход за пределы массива строк и возвращает его num элемент.
